# Deployment

Cloud provider is not selected yet. Before deployment:
1. Select provider, region, network, and ingress.
2. Configure managed identity/service role and secret manager.
3. Set HTTPS, outbound Salesforce endpoints, logs, metrics, and alerts.
4. Configure environment without embedding secrets in the image.
5. Verify health, authentication, permissions, audit persistence, timeout, and security tests.
6. Document rollback, incident response, key rotation, and retention.

Infrastructure-as-code and cloud deployment stages remain to be implemented.
